# Doom Tizen v1.20

- Switch the game engine to Crispy Doom and update its WebAssembly integration.
- Add a Tizen 5.5-compatible widget build for 2020 Samsung TVs.
- Add controller button remapping in the settings.
- Improve startup feedback and rendering initialization.

Ensure your Samsung TV is running Tizen OS version 5.5 or higher. Use
`Doom.wgt` for newer TVs and `Doom-tizen55.wgt` for 2020 TVs running Tizen 5.5.
